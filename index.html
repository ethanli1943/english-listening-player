🎧英聽小幫手

康軒英聽作業，一鍵照順序聽完

音檔由康軒官方頁面播放，小幫手只幫你：整組 Track 播完算一遍、自動接下一首、算剩餘時間、跳錯可以返回。

📩 你收到一份作業清單

按下方「開啟康軒」後，再點書籤「英聽小幫手」，清單會自動載入。

1第一次使用：把「英聽小幫手」存成書籤

每台手機或電腦只要做一次。

  1. 先按上面「複製書籤碼」。
  2. 在 Safari 按下方「分享」鈕 →「加入書籤」→ 儲存（名稱改成「英聽小幫手」）。
  3. 打開書籤列表，找到「英聽小幫手」→ 按「編輯」。
  4. 把網址欄整段刪掉，貼上剛才複製的書籤碼 → 完成。
  1. 先按上面「複製書籤碼」。
  2. 在 Chrome 按右上「⋮」→ 點「☆」把這頁加入書籤。
  3. 按「⋮」→「書籤」→ 找到剛存的書籤 → 按旁邊「⋮」→「編輯」。
  4. 名稱改成「英聽小幫手」，網址整段刪掉後貼上書籤碼 → 返回儲存。
  5. 之後使用方式：在康軒頁面點網址列，輸入「英聽小幫手」，點選下拉清單裡有星號的書籤。

2打開康軒 CD 線上聽

預設是 Cool ABC 3；其他冊別請掃自己課本上的 QR code 打開康軒頁面，一樣可以用。

▶ 開啟康軒 Cool ABC 3

3在康軒頁面點書籤「英聽小幫手」

  1. 畫面會出現「英聽小幫手」面板（手機在下方，電腦在右上）。
  2. 第一次：展開「貼上本週作業」，把老師的作業文字整段貼上 → 按「建立清單」。
  3. 按「▶ 播放」，之後就會自動一首接一首、一遍接一遍播完。
  4. 清單和進度會記在這台裝置；下次打開康軒頁再點書籤，會從上次的位置接著聽。
  5. 想給老婆或其他家長同一份清單：面板裡按「🔗 分享這份清單」，把連結傳 LINE。

本工具不下載、不儲存、不轉傳任何康軒音檔；所有聲音都由康軒官方頁面播放。手機關掉螢幕時，部分瀏覽器可能會在一首結束後停住，回到畫面按「播放」即可接續。
